# 🦁 아크워들 (ArkWordle) - 아크노바 동물카드 맞히기

[포케워들(PokéWordle)](https://www.pokewordle.app/ko) 스타일로 만든 보드게임 **《아크 노바(Ark Nova)》** 동물 카드 추리 퀴즈 웹 게임입니다.

## ✨ 주요 기능
- **7가지 단서 비교 시스템**:
  1. **크기**: 기본 크기(1~5) 및 특수 사육장(파충류 사육장, 대형 새장, 수족관) 비교 + 위/아래 화살표(`↑`/`↓`)
  2. **인접조건**: 바위 / 물 인접 조건 비교
  3. **비용**: 카드 비용 비교 (정답과 ±3 이내일 때 노란색 `≈` 및 `↑`/`↓` 표시)
  4. **추가조건**: 선행 아이콘, 2레벨 동물, 자매동물원, 자매대학 등 비교
  5. **종류**: 포식, 초식, 영장류, 파충류, 조류, 곰, 동물체험장, 해양 동물 비교
  6. **대륙**: 아프리카, 아시아, 아메리카, 유럽, 오스트레일리아 비교
  7. **능력**: 동물 고유 능력 및 산호초살이 효과 비교
- **전체 동물 카드 161종 수록**: 기본판(#401~#528) + 바다 세계 확장(#529~#560) + 프로모(#561 카피바라)
- **한글 / 초성 / 영문 / 카드번호 검색**: `ㅊㅌ`, `치타`, `Cheetah`, `401` 모두 검색 가능
- **실시간 추리 요약 노트 & 동물 도감**: 현재까지의 단서로 좁혀진 크기/비용 범위와 남은 후보 동물 목록을 실시간으로 필터링
- **원본 영문 카드 이미지 연동**: [ssimeonoff Ark Nova Cards](https://ssimeonoff.github.io/ark-nova) 스프라이트 연동
